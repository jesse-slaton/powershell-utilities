# Reorganize Script Structure with Granular Subdirectories

## Overview
Create a more granular subdirectory structure to better organize scripts by function and context. Current directories have become catch-alls with mixed purposes that make navigation and maintenance difficult.

## Current Issues

### 1. Files with Non-Descriptive Names
The following files contain ticket/change numbers or unclear names and should be renamed:

- `Scripts/Network/CHG0000000_DisableNetBiosOverTCPIP.ps1` → `Scripts/Network/Configuration/Disable-NetBiosOverTCPIP.ps1`
- `Scripts/Security/HylandCompliance-PC-0026-Package.ps1` → Remove or merge with `HylandCompliance-Package.ps1`
- `Scripts/General/move_win10.ps1` → `Scripts/ActiveDirectory/Move-Win10ComputersToOU.ps1`
- `Scripts/General/StuffedScopeArray.ps1` → `Scripts/Network/Get-NetworkLocationByScope.ps1`

### 2. Files Requiring Documentation/Review
These files need better documentation or should be moved to a review directory:

- `Scripts/General/Backup-ChromeBookmarks-Contoso.ps1` (client-specific, may not belong in repo)
- `Scripts/General/test-UIforPS7.ps1` (appears to be a test/development file)
- `Scripts/Development/Test-*.ps1` scripts (may belong in Tests/ instead)

### 3. Duplicate Files
- `GetLastComputerPolicyRefresh.ps1` exists in both `Scripts/ActiveDirectory/` and `Scripts/Network/`
  - Need to determine canonical location (likely ActiveDirectory) and update dependencies

### 4. Misplaced Module Files (.psm1)
The `Scripts/Network/` directory contains 12 module files that should be in `Modules/`:

- `AdobeReader.psm1-Package.ps1`

## Import Dependency Considerations

Before moving files, we must:

1. **Scan for import statements** that reference current paths
   - Search for `. ` (dot-sourcing)
   - Search for `Import-Module` statements
   - Search for relative path references

2. **Update all references** when moving files
   - Use find/replace with regex
   - Update any hardcoded paths
   - Update documentation

3. **Test after reorganization**
   - Run Pester tests if they exist
   - Verify no broken imports
   - Check for circular dependencies
